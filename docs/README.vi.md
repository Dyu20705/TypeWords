# TypeWords

> Ứng dụng luyện gõ và học từ vựng tiếng Anh chạy cục bộ (local-first).

## TypeWords là gì?

TypeWords giúp người học rèn luyện từ vựng tiếng Anh thông qua phản xạ gõ phím, ôn tập lặp lại ngắt quãng (FSRS) và kho từ vựng phong phú. Ứng dụng được thiết kế tối giản, không quảng cáo, hoạt động hoàn toàn cục bộ với 194 bộ từ điển (277.000+ từ) và hỗ trợ tối ưu bộ gõ tiếng Việt.

## Bắt đầu nhanh (Quick Start)

```bash
git clone https://github.com/Dyu20705/TypeWords.git
cd TypeWords
pnpm install
pnpm dev
```

Mở trình duyệt truy cập [http://localhost:5567](http://localhost:5567).
